# 📊 Módulo 22: Visualização de Dados no E-commerce

Projeto desenvolvido durante o curso de Análise de Dados da EBAC com o objetivo de explorar métricas de negócio através de recursos visuais avançados em Python.

## 🛠️ Tecnologias Utilizadas
- **Python**
- **Pandas** (manipulação tabular)
- **Matplotlib** e **Seaborn** (visualizações estatísticas e de negócio)

## 📈 Gráficos Desenvolvidos no Projeto
1. **Histograma:** Distribuição de preços do catálogo.
2. **Dispersão:** Relação entre avaliações e volume de vendas.
3. **Mapa de Calor (Heatmap):** Correlações entre variáveis numéricas.
4. **Barras:** Top 10 marcas com maior volume de produtos.
5. **Pizza:** Participação das principais categorias no sortimento.
6. **Densidade (KDE):** Curva de satisfação/notas dos produtos.
7. **Regressão Linear:** Tendência entre preço praticado e notas atribuídas.
